# Documentació de la web

Aquesta carpeta explica com funciona la web de **Dr Salinas**.
El projecte està preparat com a web estàtica per publicar amb GitHub Pages.

## Documents

- [Funcionament general](./funcionament.md): estructura de la web, pàgines,
  contingut i flux de navegació.
- [Arquitectura tècnica](./arquitectura.md): carpeta `public/`, GitHub Pages i
  assets estàtics.
- [Manteniment i assets](./manteniment.md): com editar contingut, estils i
  assets mantenint el versionat.

## Resum ràpid

La versió publicada viu a:

```text
public/
```

Per publicar-la, GitHub Pages ha d'estar configurat amb:

```text
Settings > Pages > Build and deployment > Source: GitHub Actions
```
